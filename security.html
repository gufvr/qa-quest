Conceitos para investigar

Autenticação: confirmar quem está entrando. Uma tentativa inválida deve ser negada.

Autorização: conferir quais dados e ações pertencem àquela identidade. Estar autenticado não concede acesso a todos os pedidos.

Confidencialidade: evitar que outra pessoa veja dados protegidos. Integridade: impedir alterações indevidas.

Mensagem segura: “E-mail ou senha inválidos” evita distinguir uma conta cadastrada de uma inexistente. O erro pode negar a entrada corretamente e ainda revelar informação excessiva.

Em uma aplicação real: o servidor ou a API deve validar as permissões em cada operação. Esconder botões na interface não protege dados por si só. Este laboratório representa respostas com dados locais.
